# 礼簿·人情记

微信小程序，使用微信云开发保存人情往来。当前可微信登录、建立多个账本，并在各账本内新增和查看收礼、送礼记录。共享账本、可选加密、导出、AI 记账和提醒仍待开发。

## 当前部署步骤

已完成 `users`、`ledgers` 集合及 `login`、`ledgers` 云函数部署后，继续操作：

1. 在同一云开发环境中新建 `entries` 集合，权限设为“仅管理员可读写”。小程序只通过云函数访问记录。
2. 为 `entries` 建非唯一组合索引，字段顺序：`ledgerId` 升序、`happenedOn` 降序、`_id` 降序。
3. 在微信开发者工具中右键 `cloudfunctions/entries`，选择“上传并部署：云端安装依赖”。确认云端函数列表出现 `entries`。
4. 重新编译，真机打开首页，选择一个账本并点“进入账本记账”。

## 真机验证

1. 在“婚礼”账本中新增一条“收礼”、一条“送礼”，分别填写对象、金额、日期与备注。金额可输入 `500` 或 `500.50`。
2. 下拉刷新，确认两条记录仍在，金额与日期正确；云数据库 `entries` 中的金额以 `amountFen`（分）保存。
3. 切换到另一个账本，不应看到“婚礼”账本的记录。
4. 尝试输入空对象、`0` 元、超过两位小数的金额，保存应失败，集合中不应增加记录。
5. 用另一微信账号打开小程序，应只能看到该账号自己的账本和记录。云函数会在读写前检查账本所有者。

若提示集合不存在，先创建 `entries`；若提示找不到函数，检查是否部署到正确云环境；若列表查询报索引错误，核对组合索引字段顺序。具体异常可在开发者工具控制台和云函数日志查看。

## 数据结构

- `users`：OpenID 为 `_id`，首次登录创建。
- `ledgers`：`name`、`ownerOpenid`、创建与更新时间。
- `entries`：`ledgerId`、`createdByOpenid`、`direction`（`received`/`given`）、`personName`、`amountFen`、`happenedOn`（`YYYY-MM-DD`）、`note`、创建与更新时间。

所有者身份来自云函数中的微信上下文，前端传入的账本 ID 只用于定位记录。当前版本支持新增和查看记录；修改、删除和统计可在下一阶段加入。

## 同步到 GitHub

项目可以使用 Git 同步到 GitHub。`.gitignore` 已排除微信开发者工具的本机私有配置、依赖安装目录、日志和常见密钥文件。`project.config.json` 中的 AppID 与 `miniprogram/app.js` 中的云环境 ID 仍会进入仓库；它们不是登录密钥，但建议先使用**私有仓库**。

新建空的 GitHub 私有仓库时，不要在网页端勾选 README、`.gitignore` 或许可证。取得仓库 URL 后，在项目目录执行 `git remote add origin <仓库URL>` 和 `git push -u origin main`。不要把云数据库导出的真实人情数据提交到仓库。
